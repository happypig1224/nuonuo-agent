# 小糯智肤 - 需求分析与产品理念设计规范

---

## 1. 用户画像与核心痛点剖析

小糯智肤面向的核心群体为**关注皮肤健康与科学配方的泛年轻及功效护肤群体**（涵盖屏障受损修护者、成分进阶探索者、敏感肌人群以及熬夜暗沉修复者）。

### 1.1 用户心智特征
* **信息社交化但知识碎片化**：受小红书、抖音等平台种草深刻，熟悉“早C晚A”、“刷酸”、“以油养肤”等概念，但缺乏系统的成分配伍与耐受建立知识；
* **冲动跟风与烂脸焦虑并存**：极易盲目跟风叠加高浓度酸类、视黄醇等猛药，一旦急性泛红、刺痛起皮便陷入严重的容貌焦虑；
* **排斥生硬说教与问卷填表**：厌恶长篇大论的医学名词训诫，反感每次进入系统都要填写 20 道选择题的问卷考核，渴望得到被理解、被尊重的温柔陪伴。

### 1.2 传统护肤供给侧的核心弊端
* **静态商品 vs 动态生理节律**：一套固定的护肤品无法应对内分泌、换季温湿度以及出差水质的动态变化；
* **导购专柜推销驱动**：线下 BA 与电商客服普遍背负销售指标，缺乏生物化学专业背景，推销大套盒，导致用户手中大量产品闲置；
* **传统 AI 工具冷冰冰**：大多数所谓的“AI测肤”做成了生硬的医疗化考勤系统，动辄要求“连续打卡28天”，不仅给用户施加压力，且每次会话都像“初次见面”，毫无成长记忆感。

## 2. 核心产品理念：“越用越懂你”的伴随式成长模型

围绕**自适应动态成长档案与原生多模态架构**，小糯智肤重新定义了 AI 护肤助手的产品哲学：

```
传统 AI 护肤 (机械式):
[每次对话都重头问] ──> [做 20 道测评题] ──> [强推购买大套盒] ──> [第 7/28 天定时弹窗打卡催促]

小糯智肤 (伴随式成长模型):
[随聊随拍无压力] ──> [原生多模态直接看] ──> [随手调配在用品] ──> [越用越懂你的长效成长记忆]
```

### 2.1 伴随式成长的三大支柱
1. **零填表负担，在随聊随拍中自然沉淀**：
   无需刻意做题建档。用户随手发一张自拍，或者说一句“我今天脸有点干”，系统便在后台静默提取其耐受度与习惯，自动丰富专属档案；
2. **零机械打卡与零打扰**：
   坚决不搞定时短信推送或“今日未打卡”的考核催促。小糯像一位随叫随到、情绪极其稳定的闺蜜，用户想聊就聊，随时守候；
3. **用户一等公民的“记忆掌控权”**：
   系统建立专属的 **“透明记忆卡片”** 机制，小糯记住了什么对用户 100% 透明。用户随时可在个人中心查看、纠偏或删除某条记忆，建立最高级别的安全感与信任。

1. **小糯动态 IP 形象区**：小糯软乎乎的白桃雪媚娘形态随模型语义实时交互——常态元气微笑、受损心疼抱脸、遇成分冲突急切摆手、反馈好转开心转圈；

## 4. 日常三大核心高频使用场景走查

### 场景一：开箱/逛街随手拍瓶身排雷（高频求助）
* **用户动作**：拆开刚买的新精华，随手对着包装背面拍一张：“小糯，我买了这瓶新水，能和我手头的精华一起用吗？”
* **执行链路**：
  * 原生多模态模型直接“看懂”包装上的成分清单（无需单独外挂 OCR 微服务）；
  * 后台调取 MySQL 成分冲突表进行图遍历验证；
  * 小糯快速判断并温柔给出结论：“宝子！小糯看了一下配方，里面含有高浓度水杨酸，和你正在用的 A 醇会打架哦。今晚先别叠涂，把它们分开早晚用效果更好~”。

### 场景二：洗完脸自拍看改善进展（见证好转）
* **用户动作**：几天后洗完脸，自然光下拍一张脸颊：“小糯，你看我脸颊退红了吗？”
* **执行链路**：
  * 多模态模型直接分析图像中的微小血管扩张与脱屑情况；
  * 后台调取上周的记忆对比；
  * 小糯 IP 触发开心转圈动画：“哇宝子！小糯看你脸颊两边的红血丝明显退下去一大半啦，皮肤在悄悄变坚强呢，今天咱们继续保持温和保湿就好！”。

### 场景三：日常换季/熬夜随聊咨询（无压力陪伴）
* **用户动作**：深夜打字：“今晚又加班到两点，明天起来脸肯定暗沉得不行，救救我。”
* **执行链路**：
  * 小糯调取该用户的肤质偏好记忆（排斥厚重油霜、喜欢清爽）；
  * 给出低负担的睡前三步急救法，并贴心叮嘱早点钻被窝。

## 5. 端到端高可用执行流水线

系统由 7 个严格衔接的阶段构成，保证**安全、严谨与高可用**：

```
[1. 多模态素材上传]
        ↓
[2. Redis 7 令牌桶限流] (防单用户刷量与爆破)
        ↓
[3. 确定性安全网关] (Prompt越狱与敏感图像拦截)
        ↓
[4. 上下文预载与本地快轨] (预加载 Redis 短期记忆 + MySQL 用户画像，AC 自动机秒级测成分与大类)
        ↓
[5. 确定性工具调用、知识检索与四层纵深排雷 (Grounding)] 
    ├── MySQL 四层纵深冲突防御 (单体精准查表 + 大类理化推断 + 模型医学保守守卫 + 异步审计哨兵)
    ├── Milvus 双集合检索 (skincare_knowledge 临床知识 RAG + user_episodic_memory 个人长期记忆)
    └── 药监局备案长尾商品成分定向查询工具 (Function Calling)
        ↓
[6. 原生多模态大模型推流] (高可用保障: 指数退避 + 随机全抖动 Full Jitter)
        ↓ (SSE 毫秒级首字呈现)
[7. 旁路异步上下文治理 (@Async)] (流水日志持久化 + Token水位检测摘要折叠 + 用户画像更新 + 长期记忆沉淀 + 未收录成分审计入库)
```

## 6. Agent 研发四大基石的业务具象化

要做出一个高品质的陪伴智能体，必须在代码中严格恪守以下规范：

1. **结构化 (Structuring)**：
   * 输入结构化：提取清洗后的 DTO，杜绝无边界文本在子模块中流转；
   * 记忆结构化：`user_profile_memory` 严格按照用户画像键值对存储，禁止原始无意义对话堆砌；
   * 输出结构化：护肤步骤卡片走 JSON Schema 校验，保证前端渲染稳定性。
2. **压缩 (Compression)**：
   * 短期会话：Token 水位主控（4000 Tokens）+ 轮数兜底（15 轮），保留最新 3 轮，较早历史压缩为 200 字摘要；
   * 长期记忆：同类偏好增量合并覆盖，状态机消解属性冲突；
   * 提示词工程：固定前缀适配大模型 Context Caching 机制，最大化降低首字延迟与计算成本。
3. **降噪 (Denoising)**：
   * 情绪与实体解耦：焦虑情绪交给人设做抚慰，成分冲突交给规则库做计算；
   * 包装识别去噪：瓶身反光与轻微错别字通过配方字典 Fuzzy 模糊纠错；
   * 记忆去陈旧化：用户生活环境或肤质发生改变时，自动将历史冲突标签置为废弃。
4. **热度控制 (Temperature Control)**：
   * **成分排雷 / 工具调用 ($T = 0.0$)**：绝对理智、零自由发挥，杜绝任何化学反应幻觉；
   * **方案步骤编排 ($T = 0.3$)**：严谨安全前提下微调搭配灵活性；
   * **小糯情感陪伴推流 ($T = 0.65 \sim 0.75$)**：温软生动、生动比喻、老友式情绪共鸣。

## 7. 轻量商业化与技术赋能模式

项目剥离了自营电商与实物订单履约包袱，专注于**技术价值与陪伴体验**：

* **B2B / B2B2C 品牌与机构 AI 顾问 SaaS**：
  * 向国货新锐护肤品牌、个护自媒体输出“小糯智能体”，嵌入其微信生态或私域，作为专业测肤与成分答疑助理，收取年费技术授权；
* **C 端高级记忆空间会员 (VIP)**：
  * 为深度护肤用户提供无限制多模态对比、家庭成员多肤质档案管理与专属记忆空间扩容（轻量订阅制：9.9 - 19.9 元/月）；
* **第三方客观成分导购 (轻量 CPS)**：
  * 当用户明确询问某成分代表性单品时，系统客观展示公域电商外链，系统自身不产生任何订单与履约逻辑。
